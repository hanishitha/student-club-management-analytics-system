# Student Club Management and Analytics System

A database-driven web application for managing students, clubs, events, registrations, attendance, rankings, and club performance analytics.

## Features

- Student and admin login
- Club and event management
- Student registration and attendance tracking
- Club rankings
- Participation and performance analytics
- Database-driven management system

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- XAMPP

## How to Run

1. Install XAMPP.
2. Copy the project folder into the `htdocs` folder.
3. Start Apache and MySQL from XAMPP.
4. Import `database/club_management.sql` into phpMyAdmin.
5. Open the project through `localhost` in a browser.
